# Sketch Manifest

## Design Direction

Preserve RePlate's warm, calm, community-oriented visual language while making donation fallback feel trustworthy and practical. The interface should make source verification and food eligibility more prominent than generic proximity, then use an OpenStreetMap view to help users judge whether the trip is worthwhile.

## Reference Points

- Existing RePlate Discover, listing, and donation-fallback components
- OpenStreetMap with Leaflet for the interactive map
- Verified local donation policies from official organization pages
